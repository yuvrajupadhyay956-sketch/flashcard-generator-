# 🧠 AI Flashcard Generator

An AI-powered web application that helps students create flashcards for learning, revision, and quick study.

## 🚀 Features

- 🤖 AI-powered flashcard generation
- 📚 Useful for study and revision
- ⚡ Quick generation of flashcards
- 🎨 Simple and user-friendly interface
- 💻 Web-based application
- 🧠 Helps students remember important concepts easily

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Generative AI
